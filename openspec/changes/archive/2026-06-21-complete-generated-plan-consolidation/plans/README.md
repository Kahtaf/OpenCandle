  hygiene only; no rotation forced. Residual file-permission issue → plan 001.

  false: the expiry check executes inside the better-sqlite3 transaction.

  coalescing; empty string is preserved.

  `tracker.ts:17-19` rejects both stale and zero-filled quotes.
- **`@radix-ui/react-toast` unmet dependency** — false: present in
  `gui/web/package.json:12` and the lockfile (local node_modules staleness).
- **"7 of 9 portfolio tools untested"** — false: tests exist at
  `tests/unit/tools/` (portfolio-tracker, alerts, watchlist, predictions,
  daily-report, correlation, risk-analysis).
- **Alert failure-path test gap** — substantially covered already:
  `alerts.test.ts:553-596` tests unavailable + stale paths;
  `notification-delivery.test.ts` exists. Not worth a plan.
- **Static-file symlink/TOCTOU, localhost CORS, GUI rate limiting,
  ephemeral session token** — noise for a localhost single-user tool serving
  public assets; revisit only if a real remote-access mode ships.
- **alert_rules table scan / missing index** — single-user scale (tens of
  rules); not worth doing.
- **.env.example missing flags** — partially false (`OPENCANDLE_DEBATE`,

- **Twitter cookie DB readable by local attacker** — a local attacker with
  the user's filesystem access already owns everything; OS-level disk
  encryption is the real control. Documented stance, no code change.
